Leonida Platinum is an offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI: every trophy with its official name, description and grade, a guide in our own words that cites its sources, a five-stage roadmap to the platinum, the one possibly missable trophy flagged, and a checklist whose progress is saved in the browser with export and import, kind and grade filters, and a spoiler setting that hides story trophies until they are earned. It runs entirely from its own static files with the network off.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.

## Hand it in

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
